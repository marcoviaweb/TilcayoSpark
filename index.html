01. FUNDAMENTOS

¿Qué es PySpark?

Comencemos por los conceptos que necesitas para entender los ejemplos.

DEFINICIÓN

PySpark permite utilizar Apache Spark desde Python.

Apache Spark es un motor de procesamiento de datos. Puede dividir un trabajo y ejecutarlo en varias computadoras para analizar conjuntos de datos grandes.

PySpark es su interfaz para Python. Permite leer datos, seleccionar columnas, filtrar filas, calcular valores, agrupar registros y combinar tablas mediante instrucciones de Python.

En esta guía trabajarás con DataFrames, una forma de representar y transformar datos estructurados.

¿Qué es un DataFrame?

Es una estructura organizada en filas y columnas, similar a una tabla. Cada columna tiene un nombre y un tipo de dato, como texto, entero o fecha.

¿Qué relación tiene con SQL?

Spark SQL permite consultar datos con SQL. La API de DataFrames de PySpark expresa esas operaciones con Python. Al aplicar operaciones equivalentes sobre los mismos datos, puedes obtener los mismos resultados.

¿Qué es Databricks?

Es una plataforma donde puedes ejecutar Spark en notebooks. Un notebook organiza instrucciones y resultados en celdas; puedes utilizar celdas Python y SQL en un mismo documento.

TRANSFORMACIÓN

Define qué hacer

Operaciones como select() y filter() construyen un plan y devuelven un nuevo DataFrame sin modificar el original. groupBy() prepara una agrupación; agg() calcula sus indicadores y devuelve un DataFrame.

ACCIÓN

Solicita el resultado

Una acción como show() o count() hace que Spark ejecute el trabajo necesario. Posponer la ejecución hasta ese momento se llama evaluación diferida.

Una idea para recordar

PySpark y SQL son dos formas de dar instrucciones al mismo motor de procesamiento: Apache Spark. En los ejercicios comprobarás esta relación.

Leer los CSV y habilitar SQL

El bloque define los tipos de columnas, lee los archivos y asigna a los datos los nombres clientes y pedidos para ambos lenguajes.

PYTHON: PREPARACIÓN DE LOS DATOS
from pyspark.sql import functions as F
+
+# Sustituye esta ruta si tus archivos están en otro volumen o carpeta.
+ruta_base = "/Volumes/workspace/default/practica_spark/"
+
esquema_clientes = "cliente_id INT, nombre STRING, carrera STRING, ciudad STRING"
+esquema_pedidos = """
+    pedido_id INT,
+    cliente_id INT,
+    fecha DATE,
+    categoria STRING,
+    cantidad INT,
+    precio_unitario DECIMAL(10,2)
+"""
+
+clientes = spark.read.csv(
+    ruta_base + "clientes.csv",
+    header=True,
+    schema=esquema_clientes,
+    mode="FAILFAST"
+)
+
+pedidos = spark.read.csv(
+    ruta_base + "pedidos.csv",
+    header=True,
+    schema=esquema_pedidos,
+    mode="FAILFAST"
+)
+
+# Permitir consultas SQL sobre los mismos DataFrames.
+clientes.createOrReplaceTempView("clientes")
+pedidos.createOrReplaceTempView("pedidos")
+
+# Comprobar la carga: deben aparecer 100 clientes y 1000 pedidos.
+print("Clientes:", clientes.count())
+print("Pedidos:", pedidos.count())
+clientes.printSchema()
+pedidos.printSchema()

spark.read.csv() lee cada archivo y devuelve un DataFrame. header=True indica que la primera fila contiene los encabezados.

schema define los tipos de columnas. Así, fecha se lee como fecha y precio_unitario como decimal. FAILFAST hace que Spark avise si encuentra registros incompatibles con el formato indicado.

clientes y pedidos son las variables que usarás en PySpark. createOrReplaceTempView() crea vistas temporales con esos mismos nombres para SQL, sin copiar los datos ni crear tablas permanentes.

Databricks proporciona la sesión spark. Ejecuta toda la práctica en el mismo notebook y sesión. Si reinicias la sesión, vuelve a ejecutar este bloque para recuperar los DataFrames y las vistas.
