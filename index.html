01. FUNDAMENTOS

¿Qué es PySpark?

Comencemos por los conceptos que necesitas para entender los ejemplos.

DEFINICIÓN

PySpark permite utilizar Apache Spark desde Python.

Apache Spark es un motor de procesamiento de datos. Puede dividir un trabajo y ejecutarlo en varias computadoras para analizar conjuntos de datos grandes.

PySpark es su interfaz para Python. Permite leer datos, seleccionar columnas, filtrar filas, calcular valores, agrupar registros y combinar tablas mediante instrucciones de Python.

En esta guía trabajarás con DataFrames, una forma de representar y transformar datos estructurados.

¿Qué es un DataFrame?

Es una estructura organizada en filas y columnas, similar a una tabla. Cada columna tiene un nombre y un tipo de dato, como texto, entero o fecha.

¿Qué relación tiene con SQL?

Spark SQL permite consultar datos con SQL. La API de DataFrames de PySpark expresa esas operaciones con Python. Al aplicar operaciones equivalentes sobre los mismos datos, puedes obtener los mismos resultados.

¿Qué es Databricks?

Es una plataforma donde puedes ejecutar Spark en notebooks. Un notebook organiza instrucciones y resultados en celdas; puedes utilizar celdas Python y SQL en un mismo documento.

TRANSFORMACIÓN

Define qué hacer

Operaciones como select() y filter() construyen un plan y devuelven un nuevo DataFrame sin modificar el original. groupBy() prepara una agrupación; agg() calcula sus indicadores y devuelve un DataFrame.

ACCIÓN

Solicita el resultado

Una acción como show() o count() hace que Spark ejecute el trabajo necesario. Posponer la ejecución hasta ese momento se llama evaluación diferida.

Una idea para recordar

PySpark y SQL son dos formas de dar instrucciones al mismo motor de procesamiento: Apache Spark. En los ejercicios comprobarás esta relación.

¿Para qué sirve este código?

SQL consulta directamente las tablas importadas. Para usar la API de PySpark, primero necesitas asignar esas tablas a variables de Python. Ejecuta estas instrucciones una vez, en una celda Python:

PYTHON: ABRIR LAS TABLAS COMO DATAFRAMES
from pyspark.sql import functions as F

clientes = spark.table("clientes")
pedidos = spark.table("pedidos")

from pyspark.sql import functions as F permite utilizar funciones como F.col(), F.sum() y F.round().

spark.table() abre una tabla existente como DataFrame. clientes y pedidos a la izquierda del signo igual son las variables que usarás en los ejercicios.

Databricks proporciona la sesión spark. No necesitas instalar PySpark, crear otra sesión ni registrar vistas temporales para consultar estas tablas.
